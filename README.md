# 🖼️ Image Gallery

A responsive Image Gallery developed using **HTML**, **CSS**, and **JavaScript**. The application allows users to browse images, filter them by category, and view images in an interactive lightbox.

---

# 📖 Overview

The Image Gallery is a responsive web application designed to display images in an organized and visually appealing layout. Users can filter images by category and click any image to view it in a larger lightbox.

This project was developed as part of my **Web Development Internship at SAM AI Technologies** to strengthen my frontend development skills and improve my understanding of DOM manipulation and responsive web design.

---

# ✨ Features

- 🖼️ Responsive image gallery
- 🎯 Category-based image filtering
- 🔍 Lightbox image preview
- ❌ Close lightbox using close button
- 🖱️ Click outside image to close
- ⌨️ Close lightbox using the **Escape** key
- 📱 Mobile-friendly responsive layout
- 🎨 Modern user interface

# ⚙️ How It Works

1. Open the Image Gallery.
2. Browse all available images.
3. Click category buttons to filter images.
4. Click any image to open it in the lightbox.
5. Close the lightbox using:
   - Close button (×)
   - Clicking outside the image
   - Escape key
